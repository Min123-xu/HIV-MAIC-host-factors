This folder contains the R script and accompanying documentation for performing a MAIC (Multi‑Analysis Integration of CRISPR) analysis focused on HIV‑1 resistance factors. The pipeline integrates ten ranked gene lists derived from independent genome‑wide CRISPR screens and produces a single unified gene ranking by iteratively adjusting each list’s weight and fitting a rank‑dependent decay function of the form f(x) = a·exp(‑b·x) – c·x + d. The algorithm groups lists by their original publication to avoid over‑representation, and for each gene it retains only the largest contribution per publication category before summing across categories, which yields a score that reflects both the strength and consistency of the evidence.

The input file must be a tab‑delimited text file with one gene list per line. Each line contains four mandatory columns: a publication‑level category, a unique list label, a flag indicating whether the list is RANKED or UNRANKED, and a placeholder column (usually NA) that is ignored. All subsequent columns are interpreted as gene symbols, and for ranked lists the genes must be supplied in descending order of importance, from the highest‑confidence hit to the lowest. The script also uses an internal category map that assigns the ten list labels to five distinct publication categories: Hiatt, OhAinle2018, OhAinle2020, Rathore and Zhang. This mapping ensures that multiple lists from the same study are pooled at the category level before the final gene scores are computed.

To run the analysis, simply place the script MAIC_resistance_final_all_ranked_fixed.R in the same directory as the input file resistance_lists_corrected.txt and execute it in R or RStudio. The script will print progress messages to the console and, upon completion, display a summary that includes convergence status, the number of iterations performed, and the top twenty ranked genes. Users can adjust several parameters at the beginning of the script, such as the maximum number of genes retained from each ranked list (default 2000), the stability threshold for convergence (default 0.01), and the maximum number of iterations allowed (default 100). These settings can be changed without modifying the core logic of the algorithm.

All output files are written to a directory named MAIC_resistance_final_all_ranked. The most important output is maic_ranked_genes.csv, which contains the final gene ranking together with MAIC scores, overall rank, and the number of supporting lists and publication categories for each gene. Additional files include maic_list_weights.csv that reports the final weight and fitted curve parameters for each input list, maic_iteration_history.csv that tracks weight changes across iterations, and maic_raw.tsv which provides a gene‑by‑list contribution matrix. The complete R object is also saved as maic_complete_results.rds for further custom analyses. After the run, you can quickly check whether all ranked‑list curve fittings converged successfully by running table(maic_results$list_weights$fit_ok) in the R console.
